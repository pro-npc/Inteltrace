# 🛡️ IntelTrace — Digital Forensics & Unified Investigative Analytics Platform

> **A Single Analytics Platform that Analyzes Telecom CDR/IPDR Data, Bank Statements, Social Media Activity, and On-Chain Blockchain Ledgers to Detect Anomalies, Uncover Patterns, and Generate Actionable Insights Across Digital Footprints.**

Built for **Law Enforcement Agencies (LEA), Cyber Crime Investigation Directorates, and Financial Intelligence Units (FIU)**.

---

## ⚡ Key Features

- **6-Way Data Correlation Engine**: Ingests and correlates Telecom CDR, IPDR web sessions, Banking NEFT/IMPS/RTGS ledgers, Social Media OSINT metadata, and Ethereum/Bitcoin blockchain transactions in real time.
- **Incident Synthesis & Narrative Arc**: 5-Act forensic breakdown connecting morning darknet inflow to midnight alibi collapse with mathematical certainty.
- **Tactical Geospatial Intelligence Map**:
  - Interactive Leaflet-powered dark mode map with street-level accuracy.
  - Multi-layer switching: `[Tactical Dark]`, `[Satellite Recon]`, `[Street Map]`.
  - Real landmark beacons with cellular azimuth coverage cones.
  - Chronological suspect route simulation player mapping the Goa → Mumbai overnight return corridor (~580 km).
- **IntelTrace AI Forensic Copilot (`⌘K` / `Ctrl+K`)**:
  - Global conversational AI assistant with case memory.
  - Natural language querying for alibi refutation, money trail reconciliation, and associate kickback patterns.
  - UI action driving (flies map camera, switches tabs, drafts legal text).
- **Automated Section 65B Digital Evidence Certificate Generator**:
  - Generates court-admissible certificates under **Section 65B of the Indian Evidence Act, 1872** and **§63 of Bharatiya Sakshya Adhiniyam, 2023**.
  - Includes verified **SHA-256 cryptographic hashes** of all source evidence dumps and examiner attestation seals.
- **Interactive Force-Directed Network Graph**:
  - Visual suspect-to-associate entity relationship clustering with clickable node inspection drawers.
- **Crypto ↔ Bank Reconciliation Engine**:
  - On-chain to fiat bank statement matcher with 0.03% variance tolerance and maker fee deduction proof.

## 🚀 Quick Start Guide

### 1. Install Dependencies
```bash
npm install
```

### 2. Launch Development Server
```bash
npm run dev
```
Open **`http://localhost:3000`** in your browser.

### 3. Build Production Bundle
```bash
npm run build
```
